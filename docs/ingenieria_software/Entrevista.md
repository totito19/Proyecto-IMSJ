## Objetivo

Conocer los procesos de la Sección Tránsito y las necesidades de información, contenidos y gestión para definir el alcance de la plataforma.

## Presentación y proceso actual

- ¿Qué información necesita comunicar la Sección Tránsito a la ciudadanía?
- ¿Qué canales utiliza actualmente y cómo se actualizan?
- ¿Quiénes consultan esa información con mayor frecuencia?

## Usuarios administrativos

- ¿Qué diferentes roles utilizarán el panel administrativo dentro de la IMSJ?
- ¿Hay funciones exclusivas de algunos usuarios?
- ¿Necesitan saber quién realizó cada cambio?
- ¿Cómo participa la Directora en la revisión y publicación de contenidos?

## Agenda de trámites

- ¿Cómo es el proceso actualmente?
- ¿Quién administra las franjas de disponibilidad?
- ¿Las franjas se crean manualmente?
- ¿Qué duración tiene cada franja?
- ¿Cuántos cupos debe admitir cada una?
- ¿Qué datos del ciudadano son obligatorios para realizar una reserva?
- ¿Qué debería ver el usuario luego de agendarse?

### Costo del trámite urgente

- ¿Es un costo fijo o depende de algún factor?
- En caso de depender de algún factor, ¿de cuáles?
- ¿Ese costo puede modificarse desde el panel administrativo?
- Si puede modificarse, ¿qué usuarios están autorizados a hacerlo?

## Preguntas frecuentes

- ¿Necesitan clasificar las preguntas frecuentes por categorías?
- ¿Qué categorías utilizan?
- ¿Quién administra las preguntas y sus respuestas?
- ¿Cómo se incorporan los enlaces útiles?

## Materiales de estudio

- ¿Qué formatos de archivos manejan?
- ¿Quién puede administrarlos dentro de los usuarios administrativos?
- ¿Qué público utilizará los materiales?
- ¿Los videos se publican como archivos o mediante enlaces?

## Noticias

- ¿Cómo se define el período de vigencia de una noticia?
- ¿Las noticias vencidas deben seguir siendo consultables o desaparecer completamente?
- ¿Qué portada, imágenes y enlaces necesita cada noticia?
- ¿Quién prepara, aprueba y publica el contenido?

## Operación y entrega

- ¿Qué versión se instalará para el cliente?
- ¿Dónde se alojará el sistema y qué dominio utilizará?
- ¿Cómo se organizarán soporte, cuentas y respaldos?
- ¿Qué manual y capacitación necesita el personal?
