# Requerimientos del sistema

## Requerimientos funcionales

| Código | Requerimiento funcional |
|---|---|
| RF1 | El sistema debe permitir iniciar sesión con cédula y contraseña. |
| RF2 | El sistema debe permitir consultar anuncios y noticias de la Sección Tránsito. |
| RF3 | El sistema debe permitir reservar una prueba de manejo en la versión académica. |
| RF4 | El sistema debe permitir reservar la renovación normal o urgente de la libreta de conducir en la versión académica. |
| RF5 | El sistema debe permitir acceder a materiales de estudio. |
| RF6 | El sistema debe permitir consultar preguntas frecuentes. |
| RF7 | El personal debe poder crear, modificar y administrar noticias. |
| RF8 | El personal debe poder definir el período de vigencia de una noticia. |
| RF9 | Las noticias deben admitir portada, galería de imágenes, texto y enlaces útiles. |
| RF10 | El sistema debe permitir gestionar el estado de publicación de una noticia. |
| RF11 | El personal debe poder cargar franjas para trámites normales en la versión académica. |
| RF12 | El personal debe poder cargar franjas para trámites urgentes en la versión académica. |
| RF13 | El personal debe poder cargar franjas para pruebas de manejo en la versión académica. |
| RF14 | El personal debe poder consultar la agenda diaria en la versión académica. |
| RF15 | El personal debe poder consultar la agenda semanal en la versión académica. |
| RF16 | El personal debe poder consultar la agenda mensual en la versión académica. |
| RF17 | El personal debe poder administrar materiales de estudio. |
| RF18 | El personal debe poder mantener la sección de preguntas frecuentes. |
| RF19 | Las preguntas frecuentes deben poder clasificarse por categorías. |
| RF20 | Los materiales de estudio deben admitir PDF, imágenes y videos. |
| RF21 | Los contenidos deben ser aprobados por la Directora antes de publicarse. |
| RF22 | El sistema debe ofrecer simulacros de pruebas teóricas. |
| RF23 | La ciudadanía debe poder enviar consultas y el personal debe poder leerlas en el panel. |
| RF24 | El personal debe poder adjuntar material gráfico a las preguntas de los simulacros. |

## Requerimientos no funcionales

| Código | Requerimiento no funcional |
|---|---|
| RNF1 | Controlar el acceso según el tipo de usuario y su rol. |
| RNF2 | Validar los datos recibidos antes de almacenarlos. |
| RNF3 | Mantener un historial de acciones administrativas. |
| RNF4 | Proteger los datos personales. |
| RNF5 | Ofrecer una interfaz adaptable a dispositivos móviles. |
| RNF6 | Proporcionar accesibilidad básica. |
| RNF7 | Gestionar automáticamente la vigencia de las noticias. |
| RNF8 | Evitar reservas duplicadas y el exceso de los cupos disponibles en la versión académica. |
| RNF9 | Mostrar una confirmación visual después de reservar en la versión académica. |
| RNF10 | Separar claramente los contenidos publicados de los no publicados. |
