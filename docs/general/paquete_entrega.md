# Paquete de entrega del proyecto completo

**Preparación al 21/10/2026.** Entrega prevista en el cronograma: 29/10/2026; defensa: 05/11/2026. Los cinco integrantes de RC5 presentan, entregan y defienden el proyecto completo.

## Inventario

| Componente | Contenido |
|---|---|
| Código | backend, frontend-publico y frontend-imsj; conservar la estructura relativa. |
| Datos e instalación | database.sql, migraciones, plantilla de configuración, Compose, Dockerfile, scripts de inicio/detención y README del backend. |
| Documentación | docs y docs_auxiliares: análisis, requisitos, planificación, actas, diseño, manual, operación, seguridad y evidencias. |
| Pruebas | Integración HTTP/MySQL, auditoría Bash y resultados del corte técnico. |
| Seguridad | Informes PDF, resultados SAST/DAST/Nmap y hardening, con su alcance y observaciones. |
| Respaldo de transferencia | SQL y adjuntos compatibles con la versión elegida; configuración entregada por canal protegido. Excluir credenciales y datos personales de las copias públicas. |
| Identificación | Commit exacto, inventario y tag propuesto entrega-final-2026-10-29, a crear sobre el candidato que se entregue. |

El proyecto completo incluye agenda y reservas como implementación académica. Su inclusión no habilita por sí sola un trámite institucional de licencia. Se conservan explícitamente los estados parciales y pendientes del catálogo de requisitos.

## Verificación y recepción previstas

1. Seleccionar la versión definitiva y registrar su commit y tag en el inventario.
2. Comprobar instalación, cuentas, recorridos del manual y recuperación del respaldo entregado.
3. Revisar que los enlaces y archivos del inventario se incluyan en ambas copias de entrega.
4. Presentar las limitaciones de interfaz, categorías, costo urgente y evaluación de calidad que conserva el backlog.
5. Obtener constancia de recepción con fecha, versión, inventario y observaciones; registrar por separado cualquier aceptación del cliente.

El equipo confirmó una restauración y una prueba en otra computadora satisfactorias. Esa confirmación no reemplaza la comprobación del candidato exacto seleccionado para la entrega futura.
