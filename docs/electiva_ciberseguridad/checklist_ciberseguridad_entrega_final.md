# Checklist de Ciberseguridad

## Primera entrega

- [x] Identificación de amenazas digitales.
- [x] Mapa y análisis de riesgos.
- [x] Buenas prácticas de seguridad aplicadas al proyecto.

## Segunda entrega

- [x] Autenticación, contraseñas, sesiones y permisos.
- [x] Términos y condiciones.
- [x] Política de privacidad.
- [x] Análisis estático de código (SAST) y evidencias.
- [x] Hardening de infraestructura y contenedores.

## Tercera entrega

- [x] Análisis dinámico con OWASP ZAP y Nmap.
- [x] Auditoría automatizada de la API mediante Bash.
- [x] Registro de hallazgos y medidas correctivas.
- [x] Plan de respuesta a incidentes.
- [x] Reflexión ética.
