# Reflexión ética

Las pruebas de seguridad se realizaron únicamente sobre el entorno local autorizado del proyecto IMSJ y con datos de prueba. No se atacaron sistemas externos ni se intentó acceder a información ajena.

Los resultados de herramientas como Semgrep, OWASP ZAP y Nmap se analizaron dentro del contexto del sistema. Una alerta automática no demuestra por sí sola una vulnerabilidad, y la ausencia de alertas tampoco garantiza seguridad absoluta.

Las evidencias deben conservar la fecha, el alcance y el resultado de cada prueba, sin publicar contraseñas, tokens ni datos personales. Los hallazgos se comunican al equipo para corregirlos y volver a comprobar el comportamiento afectado.

El objetivo de estas actividades fue reducir riesgos y mejorar el proyecto, respetando la privacidad de las personas y los límites acordados para la evaluación.
